# Bononi ERP

ERP interno do Grupo Bononi Acessórios.

## Stack
- React 18 + Vite 5
- Supabase (PostgreSQL)
- Lucide React (ícones)
- Recharts (gráficos)

## Desenvolvimento
```bash
npm install
npm run dev
```

## Documentação
- **`docs/STATUS-ATUAL.md`** — estado atual do sistema, o que foi entregue e pendências (ler antes de continuar).
- **`docs/GUIA-PRODUCAO-ERP.md`** — passo a passo de go-live no servidor interno.

> Produção = **servidor interno** (on-premise). O Supabase é ambiente de **teste**.
> App em produção: branch `main` → Vercel (projeto `erp`).
